# 🛒 Shopping List Application (Full Stack)

## 📌 Project Overview

This project is a full-stack Shopping List web application.
Users can create, manage and share shopping lists with items.

The application includes:
- Frontend (React)
- Backend (Node.js + Express)
- Database (MongoDB)

---

## ✨ Features

### 👤 Authentication
- User registration
- User login
- JWT authentication
- Logout

### 📋 Shopping Lists
- Create shopping lists
- View all lists
- Open list detail
- Delete lists
- Archive lists

### 📝 Items
- Add items to list
- Edit item name, description, quantity
- Mark item as done
- Delete item

### 🎨 UI
- Responsive design
- Dark / Light mode
- Language switch (EN / CZ)
- Modern design with Tailwind CSS

## ▶️ How to Run

### Clone repository
```bash
git clone https://github.com/neqarange/appShopingList.git
cd appShopingList
```

### Backend
```bash
cd backend
npm install
npm start
```

Create `.env` file:
```
PORT=5001
MONGODB_URI=mongodb://localhost:27017/shoppinglist
JWT_SECRET=secret
```

### Frontend
```bash
cd frontend
npm install
npm start
```

Frontend: http://localhost:3000  
Backend: http://localhost:5001
